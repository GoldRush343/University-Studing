# 📚 Grocery Behavior Fit (BIF)

## 1. Концепция: Адаптивная оценка категорий

Главная идея:

Нельзя требовать одинакового поведения от покупателя хлеба и покупателя вина.

Поиск работает правильно только тогда, когда:

- минимизирует усилия в рутинных товарах;
- обеспечивает качественный выбор в ассортиментных категориях.

---

# 2. Математический аппарат

Для каждого поискового запроса `q` вычисляются поведенческие коэффициенты.

## VPU — Views Per User

```math
VPU = \frac{V}{U}
```

Среднее количество просмотров на одного пользователя.

---

## CPU — Carts Per User

```math
CPU = \frac{C}{U}
```

Интенсивность добавления товаров в корзину.

---

## Loyalty Index (LI)

```math
LI = \frac{C}{I_{cart} + 0.1}
```

### Смысл

Индекс концентрации спроса.

- Если 100 человек купили 2 вида молока → LI высокий.
- Если 100 человек купили 80 разных йогуртов → LI низкий.

---

# 3. Алгоритм автоматической классификации

Система автоматически присваивает запросу один из 4 классов интента.

| Класс | Условие | Интерпретация |
|---|---|---|
| **1. Рутина** | `LI > 4.5` | Пользователь ищет конкретный товар |
| **2. Выбор вкуса** | Остальное | Исследование брендов и вариантов |
| **3. Специфичный** | `W >= 3` | Поиск по атрибутам |
| **4. Закупка** | `CPU > 1.3` | Массовое добавление товаров |

---

# 4. Формулы INTENT_SCORE

## 📍 Рутина

### Цель

Мгновенная покупка.

### Формула

```math
Score = 100 - (VPU \times 10)
```

---

## 📍 Специфичный запрос

### Цель

Найти конкретный атрибут.

### Формула

```math
Score = 100 - (VPU \times 5)
```

---

## 📍 Закупка

### Цель

Собрать корзину из множества товаров.

### Формула

```math
Score = \frac{1}{\frac{VPU}{CPU} + 1} \times 200
```

---

## 📍 Выбор вкуса

### Цель

Обеспечить исследование ассортимента с хорошей конверсией.

### Формула

```math
Score = (CPU \times 50) + (20 - VPU) \times 2
```

---

# 5. Итоговые показатели

## FINAL_SCORE

Среднее арифметическое между:

- SQI
- BIF

```math
FINAL\_SCORE = \frac{SQI + BIF}{2}
```

---

## PRIORITY_LOSS_INDEX

Главный бизнес-показатель приоритизации.

### Формула

```math
Index = (100 - FINAL\_SCORE) \times \frac{N_{searches}}{1000}
```

---

# 6. Интерпретация графиков

## Квадрант качества

### Верхний правый угол

- Поиск быстрый
- Высокая релевантность
- Зона здоровья

---

### Нижний правый угол

- SQI высокий
- Intent Score низкий

Поиск технически исправен, но продуктово бесполезен.

---

### Левый нижний угол

Зона критической деградации.

---

# 7. График деградации

Показывает, на каком этапе пользователь начинает терять интерес.

Если качество резко падает на длинных запросах:

- поисковик не понимает атрибуты;
- плохо обрабатывает уточнения;
- не умеет работать с весом, вкусом, объемом.

---

# 8. Основные преимущества BIF

- Учитывает поведенческую природу категорий
- Разделяет рутинные и исследовательские покупки
- Помогает локализовать UX-проблемы
- Приоритизирует реальные бизнес-потери
- Работает без ручной разметки

---

# 9. Резюме

BIF — это behavioral intent framework для оценки продуктовой полезности поиска.

> Хороший grocery-search — это не просто релевантность.
> Это минимизация усилий пользователя в зависимости от типа покупки.
