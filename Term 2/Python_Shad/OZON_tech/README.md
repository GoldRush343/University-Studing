# 📚 Search Quality Index (SQI) Framework

## 1. Введение и концепция

**Search Quality Index (SQI)** — это комплексная метрика оценки качества E-commerce поиска, построенная на методах реверс-инжиниринга пользовательского поведения.

### Проблема

Классическая оценка качества поиска требует:

- ручной разметки (асессоры);
- сложного NLP-анализа (TF-IDF, BM25 и др.).

### Решение

SQI оценивает качество поиска косвенно — через анализ взаимодействия пользователей с результатами выдачи.

Модель раскладывает поведение покупателей на 5 математических гипотез:

1. Понимание текста
2. Качество ранжирования
3. Понимание интента / NER
4. Замусоренность выдачи
5. Разнообразие выдачи

Для повышения устойчивости используются:

- **Байесовское сглаживание**
- **Нелинейные функции затухания**

---

# 2. Базовые переменные (сырые данные)

| Переменная | Описание |
|---|---|
| `Searches` | Количество поисковых запросов |
| `Views` | Общее количество кликов по товарам |
| `Carts` | Количество добавлений в корзину |
| `Users_search` | Уникальные пользователи, совершившие поиск |
| `Users_view` | Уникальные пользователи, кликнувшие хотя бы один товар |
| `Items_view` | Уникальные просмотренные товары |
| `Items_cart` | Уникальные товары, добавленные в корзину |

---

# 3. Байесовское сглаживание

## Penetration

```math
\tilde{P} = \frac{Users_{view} + 1}{Users_{search} + 2}
```

## Conversion

```math
\tilde{R} = \frac{Carts + 1}{Views + 10}
```

## Fatigue

```math
\tilde{F} = \frac{Views + 3}{Users_{view} + 1}
```

## Spam Focus

```math
\tilde{S} = \frac{Carts + 1}{Items_{view} + 5}
```

## Diversity

```math
\tilde{D} = \frac{Items_{cart} + 1}{Items_{view} + 2}
```

---

# 4. Суб-индексы качества

## Text Score

```math
Score_{text} =
\begin{cases}
1.0, & \text{если } \tilde{P} \ge 0.8 \\
\frac{\tilde{P}}{0.8}, & \text{иначе}
\end{cases}
```

## Rank Score

```math
Score_{rank} = 1 - e^{-20 \cdot \tilde{R}}
```

## Intent / NER Score

```math
Score_{ner} = \frac{1}{\log_2(\tilde{F} + 1)}
```

## Spam Score

```math
Score_{spam} = 1 - e^{-10 \cdot \tilde{S}}
```

## Diversity Score

```math
Score_{div} = \min(1.0, \tilde{D} \times 10)
```

---

# 5. Итоговый индекс качества

```math
TQS =
(
Score_{text} \cdot 0.2 +
Score_{rank} \cdot 0.2 +
Score_{ner} \cdot 0.2 +
Score_{spam} \cdot 0.2 +
Score_{div} \cdot 0.2
)
\times 100
```

---

# 6. Интерпретация результатов

- **80–100** — поиск работает отлично
- **50–79** — деградация качества
- **0–49** — критические проблемы поиска

---

# 7. Локализация проблем

| Индекс | Возможная проблема | Решение |
|---|---|---|
| `score_text` | Синонимы / опечатки | Spell correction |
| `score_rank` | Плохой ranking | Reranking |
| `score_ner` | Нет NER | Entity extraction |
| `score_spam` | SEO spam | Anti-spam ranking |
| `score_div` | Дубликаты | Deduplication |

---

# 8. Преимущества SQI

- Не требует ручной разметки
- Основан на поведении пользователей
- Интерпретируем бизнесом
- Масштабируется
- Подходит для real-time аналитики

---

# 9. Резюме

SQI — это behavioral-driven framework для оценки качества E-commerce поиска без ручной разметки.

> Хороший поиск определяется тем, насколько быстро пользователь находит товар и завершает покупку.
